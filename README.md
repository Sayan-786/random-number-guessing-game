# random-number-guessing-game
A simple Python number guessing game that generates a random number between 1 and 100 and challenges the user to guess it. The game provides higher/lower hints after each incorrect attempt and tracks the number of guesses taken to find the correct number.

A simple and interactive Number Guessing Game built with Python. The program randomly generates a number between 1 and 100, and the player has to guess the correct number. After each incorrect guess, the game provides a hint indicating whether the guess should be higher or lower.

📌 Features
🎲 Generates a random number between 1 and 100
⌨️ Accepts user guesses through the terminal
💡 Provides Higher or Lower hints
🔢 Counts the number of attempts
🏆 Displays the correct number and total attempts after a successful guess
